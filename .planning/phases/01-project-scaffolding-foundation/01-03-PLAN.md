# Plan 01-03: Frontend Foundation

## Objective
Scaffold the Next.js 14 App Router project in `frontend/` with TypeScript, Tailwind CSS, Lucide icons, `@xyflow/react` dependencies, a dark-themed layout shell with persistent navigation sidebar (Dashboard, Visual DAG Studio, Sentinel Keys, Live Threat Matrix), and shared TypeScript data models.
