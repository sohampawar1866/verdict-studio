# Plan 04-02: Backend Key Management & Tool Execution REST API

## Objective
Implement Key Management REST endpoints (`POST /api/mcp/keys`, `GET /api/mcp/keys`, `DELETE /api/mcp/keys/{id}`) and the secure tool execution proxy endpoint (`POST /api/mcp/execute-tool`) in `backend/app/main.py` with automatic audit log generation and WebSocket event broadcasting.

## Tasks

<task type="auto">
  <name>Task 1: Implement Key CRUD & Tool Execution REST Endpoints</name>
  <files>backend/app/main.py</files>
  <action>
    1. Implement `POST /api/mcp/keys`: generates key via `key_auth`, stores hashed record in `MCP_KEYS_DB`, returns raw key and `claude_config_snippet`.
    2. Implement `GET /api/mcp/keys`: lists all keys (masking secrets, returning prefix, permissions, created_at, is_active).
    3. Implement `DELETE /api/mcp/keys/{key_id}`: revokes key.
    4. Implement `POST /api/mcp/execute-tool`:
       - Authenticates key from `X-Haize-MCP-Key` or `Authorization: Bearer <key>`.
       - Calls `evaluate_tool_policy()` from policy engine.
       - If blocked: creates `AuditLogEntry` with status `BLOCKED`, broadcasts over WebSocket, returns 403.
       - If allowed: executes tool safely, creates `AuditLogEntry` with status `ALLOWED`, broadcasts over WebSocket, returns output.
  </action>

  <done>Key CRUD and tool proxy REST endpoints fully implemented.</done>
