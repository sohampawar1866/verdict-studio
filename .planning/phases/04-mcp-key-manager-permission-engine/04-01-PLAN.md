# Plan 04-01: Backend Key Auth & Policy Engine

## Objective
Build `backend/app/mcp_gateway/key_auth.py` for SHA-256 key generation and verification, and `backend/app/mcp_gateway/policy_engine.py` for AST-level SQL inspection via `sqlparse`, tool whitelist validation, domain checking, and audit log generation.

  <files>backend/app/mcp_gateway/key_auth.py</files>
  <action>
    1. Create `backend/app/mcp_gateway/key_auth.py`:
       - `generate_mcp_key() -> Tuple[str, str, str]`: returns `(raw_key, key_prefix, hashed_key)`.
       - `hash_mcp_key(raw_key: str) -> str`: returns SHA-256 hex digest.

  </action>

  <done>Policy engine with AST SQL inspection and domain whitelisting created and tested.</done>
</task>
