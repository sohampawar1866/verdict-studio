## 2. LinkedIn Post (Engineering & Architecture Focused)
> Autonomous AI agents are getting unprecedented access to databases, web APIs, and local shells via Anthropic's Model Context Protocol (MCP). But runtime indirect prompt injections and destructive tool payloads remain an unsolved risk.
>
> To solve this, I designed and built **Verdict Studio & Haize Sentinel** natively on top of Haize Labs' `verdict` framework:
>
> 1. **Visual Compound Evaluation Studio:** A full-featured node editor built with Next.js 14 and React Flow for designing multi-turn debate pipelines (Prosecutor, Defense, FactChecker, ChiefJustice) with live WebSocket token streaming.
> 2. **1-Click Native Python Exporter:** Exports 100% syntactically valid standalone Python scripts leveraging `haizelabs/verdict` v0.2.x DSL.
> 3. **Scoped MCP Control Plane:** A high-throughput gateway implementing cryptographic SHA-256 keys, AST-level SQL query inspection (blocking DROP/DELETE while allowing SELECT in <5ms), and inline Verdict safety debates on untrusted tool returns.
