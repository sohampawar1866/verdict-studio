# Plan 02-02: Node Configuration Drawer & DAG State Serialization

## Objective
Build the node configuration drawer (`NodeConfigDrawer.tsx`) allowing real-time tuning of prompts, models (`.via()`), temperature, scales, and extractors, along with graph state serialization, JSON export/import helpers, and pre-built debate presets (`dagPresets.ts`).
